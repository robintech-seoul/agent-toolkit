구성

  • claude/skills/ — 범용 스킬. 어떤 스택·어떤 저장소에서도 쓸 수 있고 RobinTech 제품을 알지 못합니다.
  • claude/plugins/ — 제품 도구. Robin-Cloud 운영이나 콘솔 워크플로처럼 특정 제품에 묶여 있습니다.
  • 하나의 마켓플레이스 — robintech. 다른 에이전트를 지원하게 되어도 마켓플레이스를 또 만들 필요가 없습니다.

RobinTech· agent toolkit

Claude Code marketplace

Agent tooling RobinTech builds and uses.

Add one marketplace, install what you want. The general-purpose skills work on any codebase; the product tooling plugs into Robin-Cloud.

Install

/plugin marketplace add robintech-seoul/agent-toolkit
/plugin install arch-explorer@robintech

You only add the marketplace once. The CLI does the same thing with claude plugin marketplace add ….

Plugins

robin-cloud-onboarding

/robin-cloud-onboarding:onboard

Onboard your project to Robin-Cloud — generates Dockerfiles and a keyless CI workflow, then walks you through the console setup (GitHub App, ECR, deploy config, DB, domain, TLS), verifying each step. No cluster access needed.

Read the guide →

arch-explorer

/arch-explorer:build

Map a codebase into a single self-contained HTML file you can drill through — boxes are modules, labeled arrows are the interfaces between them, each expanding to full signatures and file:line sources.

Read the README →

code-wiki

/code-wiki:build

Build and maintain a hierarchical, LLM-generated wiki over a codebase — leaf folders summarize their files, parents synthesize their children, topic pages capture cross-cutting concerns, and sync keeps it current as the source changes.

Read the README →

Layout

  • claude/skills/ — general-purpose skills. Any stack, any repo, no knowledge of RobinTech products.
  • claude/plugins/ — product tooling, tied to something specific like Robin-Cloud operations or console workflows.
  • One marketplace — robintech. Supporting another agent later won't mean another marketplace to install.
Source and contribution notes live at robintech-seoul/agent-toolkit.
